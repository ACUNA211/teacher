# Mission: App building

## Why
Understand the apps I vibe-code well enough to **debug them without leaning fully on AI**. Practice on non-commercial apps now, so I can build commercial apps later.

## Success looks like
- Read any file in my own React + TypeScript repos and explain what it does and why it's there.
- Fix a failing build, a type error, or a broken component myself, using AI as a second opinion instead of the only option.
- Read and write TypeScript types and JSON comfortably.
- Know how my apps are tested (Vitest), built (Vite), and structured well enough to steer the AI's design choices.

## Constraints
- Learn from **my own repos** (see `REPOS.md`): lessons explain what the AI built, how it works, and why.
- Weekly rhythm: Monday build review of last week's commits.
- Coming from C++, C#, Python: compare new ideas to those languages when it helps.

## Out of scope (for now)
- Other frameworks (Vue, Angular, Svelte), native mobile, backend-heavy architecture.
- Commercial concerns (billing, scaling, compliance) until the first commercial app.
