# App building Resources

## Knowledge

- [react.dev: Learn React](https://react.dev/learn)
  The official React docs, written for modern React (hooks, function components). Use for: components, state, effects, and anything in React 19.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  The official language guide. Use for: types, generics, narrowing. Start with "TypeScript for Java/C# Programmers".
- [TypeScript for Java/C# Programmers](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes-oop.html)
  Maps C# habits onto TypeScript and warns where they don't transfer. Use for: early lessons.
- [MDN Web Docs: JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
  The reference for the JavaScript underneath TypeScript. Use for: modules, promises, arrays, JSON.
- [Vite Guide](https://vite.dev/guide/)
  Official docs for the dev server and build tool. Use for: `npm run dev`/`build`, config, env variables.
- [Vitest Guide](https://vitest.dev/guide/)
  Official docs for the test runner. Use for: reading and writing the repos' tests.

## Wisdom (Communities)

- [r/reactjs](https://www.reddit.com/r/reactjs/)
  Large, moderated React community with a beginner thread. Use for: "is this the idiomatic way?" questions.
- [Reactiflux Discord](https://www.reactiflux.com/)
  Long-running React chat community. Use for: real-time debugging help.

## Gaps

- A good source on debugging React apps in the browser (DevTools, React DevTools).
