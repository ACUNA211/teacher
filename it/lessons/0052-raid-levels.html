Many drives, one volume: RAID 0, 1, 5, 6 and 10

About 10 minutes. Lessons 0049 and 0051 covered single drives. RAID (redundant array of independent disks) combines several drives so the computer sees one, for more speed, more redundancy, or both.[1] The win: given a pile of drives and a RAID level, say how many can fail and how much space you get.

Why this matters at work

Messer's key warning: RAID is not a backup.[1] RAID protects against a drive dying. If a user deletes a folder, or ransomware encrypts a file share, RAID faithfully writes that change to every drive at once. Recovering it takes a real backup or version history (for example, file versions in a company cloud drive). When a small office's NAS shows "degraded," one drive has failed and the array has no safety margin left until it's replaced and rebuilt.

1. Three building blocks

TechniqueWhat it doesGives you
StripingSplits data into chunks spread across drives, read and written in parallelSpeed and full capacity, no protection
MirroringWrites an identical copy to a second driveSurvives a drive failure; costs half the space
ParityStores extra math (like memory parity, but able to rebuild) so a missing drive's data can be recalculatedProtection for the cost of one drive's space

2. The five levels on the exam

Messer covers RAID 0, 1, 5, 6 and 1+0.[1] n = number of drives, all the same size.

LevelHowMin drivesDrives that can failUsable space
RAID 0Striping20: one failure loses everythingn (all of it)
RAID 1Mirroring21Half
RAID 5Striping with parity31n − 1
RAID 6Striping with double parity42n − 2
RAID 10 (1+0)A stripe of mirrors41 per mirror pairHalf

Minimums, failure tolerance and capacity from vendor RAID references.[2][3] Memory hook: RAID 0 = zero protection. RAID 10 can survive two failures only if they're in different mirror pairs.

When a protected array loses a drive it keeps running degraded. Replace the drive and the array rebuilds the missing data from the mirror or parity. A hot spare is an idle drive the controller uses to start that rebuild automatically.[2]

Rule of thumb

0 = fast, fragile. 1 = a copy. 5 = lose one drive's space, survive one failure (3+ drives). 6 = lose two, survive two (4+). 10 = mirrors striped together, half the space (4+). And always: RAID is not a backup.

Try it (3 minutes)

  1. On paper: you have four 4 TB drives. Work out the usable space for RAID 0, RAID 5, RAID 6 and RAID 10, and how many drives each can lose.
  2. Then check yourself below.
  3. Optional, on a Windows PC: Get-VirtualDisk | Format-Table FriendlyName, ResiliencySettingName, HealthStatus. Windows' own software RAID, Storage Spaces, calls its layouts Simple (striping), Mirror and Parity.[4] Most laptops return nothing: no Storage Spaces set up.
Four 4 TB drives: usable space and failures survived for RAID 0, 5, 6 and 10? (then click to check)

RAID 0: 16 TB, survives 0. RAID 5: 12 TB (one drive's worth goes to parity), survives 1. RAID 6: 8 TB, survives any 2. RAID 10: 8 TB, survives 1 (2 if they're in different mirror pairs).

Practice

Answer from memory before scrolling back up.

A small office buys a NAS with three drives. It must keep running if one drive fails, and use as much space as possible. Which level fits?

RAID 5 needs at least three drives, survives one failure and gives up only one drive's worth of space to parity.[2] RAID 0 has no protection, RAID 1 mirrors two drives (half the space), and RAID 6 needs at least four.

A video editor's PC stripes two SSDs in RAID 0 for speed. One SSD dies. What happens to the data?

RAID 0 splits every file into chunks across both drives and has no redundancy, so losing one drive loses all the data in the array.[3] There's no mirror and no parity to rebuild from.

A user deletes an important folder on a file server that uses RAID 1. How do you get it back?

The mirror received the delete at the same moment, so both drives no longer have the folder. RAID is not a backup: it protects against drive failure, not deletion, corruption or ransomware.[1] Restore from a backup or file version history.

A server has six 2 TB drives in RAID 6. How much usable space does it have?

RAID 6 uses two drives' worth of space for double parity: (6 − 2) × 2 TB = 8 TB, and it survives any two failures.[2] 10 TB would be RAID 5; 6 TB would be RAID 10.

From memory: the three building blocks, and for RAID 0, 1, 5, 6 and 10 the minimum drives and how many can fail. (then click to check)

Striping (speed), mirroring (copy), parity (rebuild by math). RAID 0: 2 drives, 0 failures. RAID 1: 2, 1. RAID 5: 3, 1. RAID 6: 4, 2. RAID 10: 4, 1 per mirror pair. RAID is not a backup.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

Two SSDs use similar flash chips, but one is SATA and one is NVMe. Why is the NVMe one so much faster? (lesson 0049, 3 days ago)

NVMe talks over PCIe lanes with many deep command queues. A SATA SSD uses AHCI (one queue of 32 commands, built for spinning drives) over a SATA link that tops out around 600 MB/s.

A user's DSL line plugs into the modem with a smaller plug than the Ethernet cable. Name both connectors, and the one on a cable modem's coax. (lesson 0045, 7 days ago)

DSL/phone: RJ11 (smaller, 6-position). Ethernet: RJ45 (8P8C). Cable modem coax: the threaded F-connector.

What's the only difference between T568A and T568B, and when do you get a crossover cable? (lesson 0038, 14 days ago)

The orange and green pairs swap places. Same standard on both ends = straight-through; 568A on one end and 568B on the other = crossover. Auto-MDIX on modern ports makes crossovers mostly unnecessary.
