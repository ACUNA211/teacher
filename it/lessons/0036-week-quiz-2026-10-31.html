How to take it

No scrolling back to the lessons until you've answered. A wrong answer followed by the explanation sticks better than a right answer you looked up. Each explanation links to the lesson that taught it, so you know exactly what to reread.

A cloud-hosted ticketing system crawls every Monday at 9 AM when the whole company signs in, then is fast again by noon. Nothing has failed or gone offline. Which cloud characteristic would fix this?

The problem is too much demand, not something breaking, so the answer is rapid elasticity: capacity grows for the Monday rush and shrinks afterwards, without users noticing. High availability is about surviving a failure; metering is how the extra capacity is billed. See lesson 0033.

A user reads work email on an old desktop that was set up years ago with incoming mail on port 110. They just added the same account to their phone, and the phone's inbox is nearly empty, while the desktop shows every message. What explains it?

Port 110 is POP3, the "post office": the desktop collects the mail and typically removes it from the server, so there's nothing left for the phone to see. IMAP (143, or 993 with TLS) keeps mail on the server and syncs every device. SMTP (25/587) only sends. Fix: move the desktop to IMAP. See lesson 0004.

A technician builds a test VM on their laptop using the hypervisor's default shared-address (NAT) network. The VM browses the web fine, but a coworker on the office LAN can't reach the test web server running inside it. Why?

In NAT mode the VM goes out using the host's IP address: it can start connections, but others can't start one to it. To make it look like any other device on the LAN, switch it to bridged (a Hyper-V external switch), where it gets its own MAC and its own DHCP lease. It browses, so it clearly has a virtual NIC. See lesson 0031.

A shared conference-room monitor looks sharp and fast, but people sitting at the sides of the table say the colors look washed out and shifted. The person straight in front sees it fine. Which panel type is this most likely?

TN (twisted nematic) is the fastest and cheapest LCD, and its known weakness is that colors shift when viewed off-center. IPS is the one with the widest viewing angles (the right pick for a shared screen); VA is the contrast champion; OLED has no viewing-angle problem of this kind. See lesson 0034.

The lobby guest Wi-Fi is a single /24 whose router is also the DHCP server, with an 8-day lease. About 400 different visitors' phones joined during a busy conference this week. Now new visitors get a 169.254.x.x address, while staff phones that joined earlier still work. What's the most likely cause?

A /24 has at most 254 addresses, and an 8-day lease keeps each one tied to a phone that left days ago. Phones that already hold a lease keep renewing at T1 (half the lease); new ones get no Offer, so Windows and phones fall back to APIPA. Fix: shorten the lease to hours (normal for guest Wi-Fi) or enlarge the scope. A wrong DNS option would still hand out addresses, and there's no relay when the server is on the same subnet. See lesson 0014.

Your company's Microsoft 365 tenant runs on the same infrastructure as thousands of other organizations, yet none of them can see your mail or files, and Microsoft runs everything up to the finished apps. Which set of terms fits it?

Microsoft runs the whole stack up to the app: SaaS. It's a provider's cloud open to any paying customer: public. Many customers share the same system while each one's data stays separate: multitenant (that's why your organization is called a tenant). Dedicated would mean nobody shares the hardware. See lesson 0032 and lesson 0033.

A new database server must use a volume on central storage as if it were its own internal disk, formatting it itself, over a dedicated high-speed network. Which do you build?

"Like its own disk" and "formats it itself" mean block-level access: that's a SAN, usually on its own isolated fast network (Fibre Channel or iSCSI). A NAS is a device sharing files by name over SMB or NFS. SAN = disk (blocks), NAS = share (files). See lesson 0017.

A technician installs VirtualBox on a new desktop. Creating a 64-bit VM fails, and Task Manager → Performance → CPU shows Virtualization: Disabled. What's the fix?

Every hypervisor, type 1 or type 2, needs the CPU's virtualization extensions: Intel VT-x or AMD-V. "Disabled" in Task Manager means they're switched off in the UEFI/BIOS settings, so turn them on there. A type 1 hypervisor would need them just as much; memory and networking don't change the flag. See lesson 0031 and lesson 0030.

Staff and guest VLANs both span two switches joined by a single cable. Staff PCs on switch A reach each other fine, as do staff PCs on switch B, but staff on A can't reach staff on B. What's the most likely misconfiguration?

A link that carries several VLANs between switches must be a trunk, tagging each frame with its VLAN (802.1Q). If it's set up as an access port for one VLAN, the other VLAN can't cross it, so each switch is an island for that VLAN. A VPN is for joining distant sites, not two switches in one building. See lesson 0016.

Both screens below run at their native resolution. User A moved from a 14-inch 1080p laptop to a 27-inch 1080p monitor and says text looks "bigger but grainy." User B moved from that 27-inch 1080p monitor to a 27-inch 4K one and says text is "crisp." Which attribute explains both?

Pixel density (pixels per inch) depends on resolution and size together. The same 1080p spread over 27 inches is about 82 PPI instead of 157 on the 14-inch laptop: bigger, grainier. 4K on 27 inches is about 163 PPI: crisp. Refresh rate is smoothness of motion, gamut is range of color. See lesson 0035.

A company moved an old line-of-business app off its own server onto a Windows VM it rents from a cloud provider. A month later the VM is infected through a Windows flaw that had a patch available for weeks. Whose job was installing that patch?

A rented VM is IaaS: the provider runs the hardware, network and hypervisor; the customer runs the OS, its patches, the apps and the data. IaaS leaves the most to the customer of the three service models. With PaaS or SaaS the provider would patch the OS. See lesson 0032.

A new access point needs about 25 W. Plugged into a closet switch's PoE port, it powers up, then keeps rebooting. A laptop plugged into that same port gets a network connection fine. What's the likely cause?

Data works (the laptop proves the port and VLAN), so think power. Plain PoE (802.3af) guarantees only about 13 W at the device; 25 W needs PoE+ (802.3at) or better. Fix: a PoE+ port, or a PoE+ injector (midspan) between the switch and the access point. The ONT sits at the internet edge, not in the closet. See lesson 0021.

A tablet was dropped and its glass cracked in one corner. Taps work everywhere, even over the crack, but a dark blotch near the crack is slowly spreading across the picture. Which part is damaged?

A touchscreen is two layers doing two jobs. Touch works everywhere, so the digitizer is fine; the picture is what's broken, so it's the display panel. A driver can't cause damage that grows from a crack, and a backlight fault darkens the whole screen evenly. On many tablets the two layers are fused and replaced as one part anyway. See lesson 0034.

Security asks you to open a suspicious attachment to see what it does, without risk to your Windows 11 Pro laptop, and with nothing left behind afterwards. What's the quickest built-in way?

That's the sandboxing use of a VM, and Windows Sandbox is built into Pro: isolated from the host, and everything in it is thrown away when it closes. A container shares the host's kernel (lighter isolation), a bridged VM sits right on the office network, and a dual boot shares the same disk. See lesson 0030.

To troubleshoot a slow app, a technician plugs a laptop running a packet capture into a spare port on an unmanaged switch, hoping to watch traffic between two other PCs. The capture shows only broadcasts and the laptop's own traffic. Why?

A switch learns which MAC address lives on which port and sends each frame only to the port of its destination MAC, so a third port never sees the conversation (a hub would have flooded it everywhere). Routers, not switches, decide by IP. To watch it, use port mirroring on a managed switch, or a network tap. See lesson 0020 and lesson 0019.

Explain it in your own words

Say or write the answer before you open each one. If you can explain it to a coworker, you know it.

A developer asks why their app should ship as a container instead of a VM. Explain the one structural difference, one advantage it brings, and one trade-off. (lesson 0031)

A VM carries a whole operating system, kernel included. A container carries only the app and what it needs, and shares the host's kernel. Advantage: small, starts in seconds, runs the same on a laptop, a server or the cloud. Trade-off: lighter isolation than a VM, and a Linux container needs a Linux kernel underneath.

A manager says "we moved to the cloud, so security is the provider's problem now." Explain where the line sits in IaaS, PaaS and SaaS, and what never moves. (lesson 0032)

IaaS: the provider runs hardware and hypervisor; you run the OS and everything above. PaaS: the provider also runs the OS and runtime; you bring code and data. SaaS: the provider runs the finished app; you run users and settings. In every model the customer keeps its data, accounts, access and devices, so a phished account is still yours.

A user lowered their new monitor's resolution "to make the text bigger," and now it's blurry. Explain why, and what they should have done. (lesson 0035)

An LCD or OLED panel has a fixed grid of pixels, its native resolution (marked Recommended). Any other resolution gets stretched across pixels that don't line up, which softens text. Set it back to native and raise Scale (125%, 150%) instead: bigger and still sharp.

Walk through how a laptop gets a DHCP address, and what it does at 50%, 87.5% and 100% of its lease. (lesson 0014, 22 days ago)

DORA: Discover (client broadcasts), Offer (server proposes), Request (client asks for it), Acknowledge (server confirms). At 50% (T1) it asks the same server to renew. At 87.5% (T2) it broadcasts to any DHCP server. At 100% the address is gone; it starts DORA again, and with no answer Windows falls back to APIPA (169.254.x.x).

The office internet is down. Explain what the demarcation point is, which box it usually is on a fiber line, and why it decides who you call. (lesson 0021, 15 days ago)

The demarcation point is where the provider's responsibility ends and yours begins. On fiber it's usually the ONT, which converts light to Ethernet: the provider owns everything up to and including it. A fault on their side means calling the provider; on your side (router, switch, cabling) it's yours to fix.
