How to take it

No scrolling back to the lessons until you've answered. A wrong answer followed by the explanation sticks better than a right answer you looked up. Each explanation links to the lesson that taught it, so you know exactly what to reread.

A technician changes a BitLocker laptop's boot order to run a USB diagnostic tool, then sets the order back. On the next normal start, the laptop shows the BitLocker recovery screen. What should the technician have done first?

BitLocker's key is sealed to the TPM's boot measurements. Boot-order and other firmware changes alter those measurements, so the TPM holds the key back and BitLocker asks for the recovery key. Suspending BitLocker first lets the change through; it resumes after the restart. Clearing the TPM would destroy the key, and touching Secure Boot is one more change that triggers recovery. See lesson 0060 and lesson 0059.

A user says "the internet is down." Their PC can print to the printer on the same subnet, but can't reach a known public server even by IP address. ipconfig /all shows DHCP Enabled: No, address 192.168.1.57, mask 255.255.255.0, and a blank default gateway. What's the most likely cause?

Someone typed the settings in by hand (DHCP Enabled: No) and left out the default gateway, the "where do I send everything that isn't local?" setting. Local things work, the internet doesn't. It isn't APIPA (that would be 169.254.x.x), DNS can't be the problem when even a raw IP fails, and the printer works. Fix: switch the adapter back to DHCP, or add the gateway. See lesson 0001, 63 days ago.

A team's new thin laptops run Windows 11 well, but the label-printer driver that works on the old Intel laptops refuses to install: "not compatible with this platform." $env:PROCESSOR_ARCHITECTURE returns ARM64. What's the most likely cause?

ARM is a different instruction set, not a slower x86. Windows 11 on ARM can emulate most x64 apps, but drivers must be built for ARM64. Ask the maker for an ARM64 driver (or keep that job on an x64 PC). 32-bit Windows doesn't exist for ARM laptops, and virtualization and multithreading have nothing to do with driver installs. See lesson 0061.

To check a DNS server, a technician runs Test-NetConnection against it on port 53 and gets TcpTestSucceeded: True. Clients' name lookups still time out. Why doesn't that test settle the question?

DNS uses port 53 on both TCP and UDP, and ordinary lookups are quick UDP questions. Test-NetConnection only tests TCP (there's no UDP "connection" to test), so a TCP success doesn't prove UDP 53 gets through a firewall. Clients always use ephemeral ports to reach a server's well-known port, and a port test doesn't need ping. See lesson 0002, 62 days ago.

Last weekend a user cleaned the dust off their desktop's CPU heat sink, wiped the base clean and refitted it. Since then the PC shuts itself off after about ten minutes of gaming. The fans spin normally. What's the most likely cause?

Wiping the base removed the thermal paste. Without it, microscopic air gaps sit between chip and heat sink, air carries heat badly, and the CPU overheats until it protects itself by shutting down. Clean both surfaces and apply a thin fresh layer (or a new pad). Backwards fans would leave the PC hot even at idle, Secure Boot only acts at startup, and an x4 slot means slower graphics, not shutdowns. See lesson 0063.

A security review finds that an internal HR app checks usernames against the directory with traffic anyone on the network could read. The vendor supports an encrypted connection from the first byte. Which port should the firewall allow?

Directory lookups are LDAP, which on 389 is unencrypted by default. LDAPS wraps the same protocol in TLS on 636, encrypted from the first byte: the same pattern as HTTP 80 vs. HTTPS 443. 445 is SMB file sharing and 139 is the legacy NetBIOS session path. See lesson 0005, 59 days ago.

A school wants its exam-room PCs so locked down that nobody can even start them until a staff member types a password at power-on, before Windows loads. Which password do you set?

The user/system password is asked for at power-on: no password, no boot. The supervisor/admin password only guards the setup screen and lets the PC start freely (right for a kiosk, wrong here). A BitLocker recovery key isn't a password you set, and a Windows password comes after the firmware has already booted. Many schools set both. See lesson 0059.

An older office PC fails the Windows 11 upgrade check on Secure Boot. msinfo32 shows BIOS Mode: Legacy, and the board's manual says it supports UEFI. The system disk is MBR. What change does the planned fix need?

Secure Boot is a UEFI feature, and it can't be on while the board pretends to be an old BIOS (legacy/CSM mode). UEFI boots Windows from GPT disks, so the disk must be converted and CSM turned off; then Secure Boot can be enabled. A BIOS update alone leaves it in legacy mode, fTPM solves a different requirement, and a CMOS clear just resets settings. Plan it as a job, not a quick toggle. See lesson 0058.

A user's Bluetooth headset works with their phone, but it won't show up on their new laptop, sitting right next to it. Get-PnpDevice -Class Bluetooth shows the laptop's radio as OK. What's the best next step?

Bluetooth devices must be paired once, and a headset already connected to a phone usually won't advertise itself until it's put in pairing mode (disconnect it from the phone if needed). The radio shows OK, so the driver is fine, and NFC is a tap-range technology, not a headset link. Bluetooth uses 2.4 GHz and reaches about 10 m; four centimeters is NFC's range. See lesson 0009, 55 days ago.

A streamer plugs their game console's HDMI output into one of the HDMI ports on their PC's new graphics card, hoping to record gameplay. Nothing appears anywhere. What's the problem?

Ports are a direction clue. A graphics card's HDMI ports send video out to monitors; they can't take a signal in. Bringing video in from a console or camera is a capture card's job (usually PCIe, for the high throughput). Cable type, lanes and integrated graphics don't change which way a port faces. See lesson 0062.

A laptop protected by BitLocker with a TPM + PIN is stolen. The thief starts it and keeps guessing PINs at the startup prompt. What stops them from simply trying every PIN?

The TPM has anti-hammering protection: after too many wrong guesses it locks out for a while, so brute-forcing the PIN would take impossibly long. And the key never leaves the TPM. An HSM is a central device for many servers, not something inside a laptop, and Secure Boot only checks boot software signatures. See lesson 0060.

An hour ago an admin pointed www.example.com's A record at a new web server. Some users now reach the new server, others still reach the old one. The record's TTL was 86400. What's the most likely explanation?

The TTL (86400 seconds = one day) says how long clients and other DNS servers may cache the answer. Anyone who looked the name up before the change can keep using the old address for up to a day. Next time, lower the TTL a day ahead of a planned move. MX is for mail, an AAAA record holds IPv6 rather than overriding IPv4, and DHCP hands out client settings, not web-server addresses. See lesson 0012, 52 days ago.

An office desktop's fans roar at full speed all day, even when it's idle. The fans and vents are clean, and the hardware monitor shows low temperatures. What's the most likely cause?

The board's fan controller follows the mode set in the BIOS/UEFI: maximum cooling, minimum noise, or full speed all the time. Cool temperatures plus loud fans point at the setting, not a cooling fault. Switch to a quieter profile. Dried paste or a loose heat sink would show high temperatures, and CPU threads don't control fans. See lesson 0063 and lesson 0059.

A busy lobby's guest Wi-Fi has a pool of 100 addresses and an 8-day lease. By mid-afternoon, new visitors' phones get 169.254.x.x addresses, though most of the morning's visitors left hours ago. What's the best fix?

The pool is exhausted: phones that left still hold their addresses until their 8-day leases run out, so new phones get no answer and fall back to APIPA. A short lease (an hour or two) recycles addresses quickly, which is exactly what guest Wi-Fi needs. Reservations and exclusions both take addresses out of the pool, and the gateway option doesn't affect who gets an address. See lesson 0014, 50 days ago.

A user added a second RAM stick to their desktop. Now it powers on, the fans spin, and it beeps a pattern but never shows the logo. What's the best next step?

Beeps with no logo mean POST found a hardware problem before anything else got a turn, and the only change was the RAM. Reseat it (or remove it and check it matches the board's type). Windows, Secure Boot and the boot order all come after POST, so none of them can be the cause. The board manual decodes the beep pattern. See lesson 0058.

Explain it in your own words

Say or write the answer before you open each one. If you can explain it to a coworker, you know it.

A coworker asks why updating the BIOS on a laptop made it ask for a BitLocker recovery key, when "nothing about the drive changed." Explain it, and how to avoid it next time. (lesson 0060)

At each start, the boot code is measured into the TPM, and BitLocker's key is sealed to those measurements. New firmware means new measurements, so the TPM won't release the key and BitLocker falls back to the recovery key. That's the protection working: a changed boot could be an attacker. Next time, suspend BitLocker before the update; it resumes after the restart.

Legacy BIOS vs. UEFI: give four differences, and explain why a PC in legacy mode can't pass the Windows 11 check. (lesson 0058)

UEFI: graphical setup with a mouse, boots from GPT disks over 2 TB, can use USB and network before the OS, has Secure Boot, required by Windows 11. Legacy BIOS: text setup, MBR disks, no boot past ~2 TB, no Secure Boot. In legacy (CSM) mode Secure Boot can't be on, so the check fails.

Trace the heat from a CPU to the room, naming each part, and explain why you never refit a heat sink with nothing between it and the chip. (lesson 0063)

Chip → thermal paste or pad → heat sink fins → air → fans push it out of the case (front in, back and top out). Liquid cooling swaps the middle for block → pump → radiator → fans. Metal surfaces that look flat still leave microscopic air gaps, and air carries heat badly; paste or a pad fills them. A pad is single use.

A laptop shows a 169.254.x.x address. Explain what that is, why the user can reach almost nothing, and where you'd look first. (lesson 0001, 63 days ago)

It's APIPA: the PC asked for an address, no DHCP server answered, so Windows gave itself a link-local one. It comes with no gateway and no DNS server, so nothing beyond the local link works. Look at the connection to DHCP: the cable or Wi-Fi, the switch port, then the DHCP server itself (or a full pool). It's not the user's account.

DHCP exclusion vs. reservation: what each does, and which you'd use for a network printer and which for a router set by hand. (lesson 0014, 50 days ago)

An exclusion says "never hand out these addresses": for devices configured by hand, like the router or servers. A reservation says "always give this address to that MAC": the device still uses DHCP but keeps the same IP, which suits a printer. The router gets an exclusion; the printer a reservation.
