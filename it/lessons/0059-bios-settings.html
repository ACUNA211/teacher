Five switches in the firmware: BIOS settings

About 10 minutes. Yesterday: what the BIOS/UEFI is and what it does at power-on. Today: the settings inside its setup screen that a technician actually changes.[1] The win: given a request ("stop USB boot", "lock the setup screen", "boot this old tool"), name the one setting to change.

Why this matters at work

Firmware settings are part of device security. Intune can even manage some of them remotely on supported PCs through DFCI (Device Firmware Configuration Interface): for example, block booting from USB and stop the user from changing UEFI settings.[3] And when a laptop fails a "Secure Boot" compliance check and the user loses access to company apps, today's Secure Boot switch is where the fix lives.

0. Before you touch anything: save what's there

A wrong firmware setting can stop a PC from booting. So record the current settings first; a phone photo of each screen is enough. If something breaks, go back in and set things back the way they were.[2]

1. The five settings

SettingWhat it doesTypical reason to change it
Boot optionsWhich devices may boot (SSD, USB, network/PXE, optical) and in what order; each can be enabled or disabled[1]Boot an installer from USB; stop anyone booting their own USB stick
USB permissionsTurn USB ports (or USB boot) on or off in the firmware[1]Locked-down kiosk or lab PC
Fan settingsFan profiles: quieter and warmer, or louder and cooler; the hardware monitor shows temperatures and fan speeds[5]Noisy PC in an office; a PC that overheats under load
Secure BootUEFI checks digital signatures so only trusted boot software runs[1]Keep it on; turn off only for an OS or tool that doesn't support it, then back on
PasswordsUser/system password: needed to start the PC at all. Supervisor/admin password: needed to change firmware settings[4]Stop users changing boot order or turning Secure Boot off

Two details worth knowing. Most PCs also have a one-time boot menu (often F12, depends on the maker): boot from USB once without changing the saved boot order. And other common switches live in the same screens, such as virtualization support (Intel VT-x / AMD-V), which you met in lesson 0030.

Rule of thumb

Photo first, then change. Boot order picks the device; boot options allow or block it. User password = can't start. Supervisor password = can't change settings. Secure Boot stays on unless something unsigned truly needs it off, and then goes back on.

Try it (2 minutes)

You can peek at two firmware settings from inside Windows without rebooting:

  1. Virtualization: Task Manager → Performance → CPU. Bottom right says Virtualization: Enabled or Disabled (a firmware switch).
  2. Firmware boot entries: open PowerShell or Command Prompt as administrator and run:[6] 
    bcdedit /enum firmware
    Look at the Firmware Boot Manager entry's displayorder: that's the firmware boot list (Windows Boot Manager, USB, network…), in order.
Before checking: the list shows Windows Boot Manager first and a USB entry second. A user plugs in a bootable USB stick and restarts. What boots? (then click to check)

Windows, because the firmware tries the boot order top-down and the SSD's Windows Boot Manager works. To boot the stick, use the one-time boot menu or move USB up (if USB boot isn't disabled).

Practice

Answer from memory before scrolling back up.

A training-room PC must never boot from USB sticks people bring in, but its USB keyboard and mouse must keep working. Which firmware change fits best?

Disabling USB as a boot option stops USB booting while the ports still work in Windows.[1] Turning off every port would kill the keyboard too. Add a supervisor password so nobody turns it back on.

A lobby kiosk PC: anyone should be able to power it on and use it, but nobody should be able to change the boot order. Which password do you set?

The supervisor/admin password guards the setup screen; the PC still starts freely. A user/system password would stop everyone at power-on.[4] Windows and BitLocker passwords don't protect firmware settings.

A technician tries to boot an old, unsigned diagnostic tool from USB. The firmware blocks it with a security message. The boot order is correct. What do they change, for now?

Secure Boot blocks boot software without a trusted signature.[1] Turn it off only for the job, then back on; otherwise the PC can fail a "Require Secure Boot" compliance check.

You're asked to change several firmware settings on a desktop you've never seen before. What do you do first?

A bad setting can stop the PC booting. With a record (photos are fine) you can put everything back.[2] Pulling the CMOS battery may reset everything to defaults, which is the opposite of careful.

From memory: the five setting groups in today's table, and the difference between the two firmware passwords. (then click to check)

Boot options, USB permissions, fan settings, Secure Boot, passwords. User/system = needed to start the PC; supervisor/admin = needed to change firmware settings.

Some motherboards carry two BIOS chips. What is the second one for, and when does it save you? (lesson 0058, 1 day ago)

It's a backup copy of the firmware. If the main chip is corrupted, for example by a power cut during a firmware update, the board can recover from the backup instead of failing to POST.

RAID 5: minimum number of drives, how many can fail, and why it's still not a backup. (lesson 0052, 7 days ago)

At least 3 drives; it survives 1 drive failure (parity rebuilds it). It's not a backup: deleted files, ransomware or a corrupted file are "faithfully" kept on every drive.

A home office has a DSL line and a cable-TV line. Which connector does each modem use? (lesson 0045, 14 days ago)

DSL: RJ11 (smaller phone-line jack). Cable: F-connector (threaded, on coax).
