What the processor can do: CPU features

About 10 minutes. In lesson 0056 you matched a CPU to its socket. Today: what's printed on the spec sheet once it's in. Four features the exam lists: 32-bit vs. 64-bit, ARM, cores and multithreading, and virtualization support.[1][2] The win: read a PC's CPU line in Task Manager and explain every number on it.

Why this matters at work

Windows 11 runs only on 64-bit processors (x64 or ARM64), and when you package an app in Intune you can set which architectures it installs on, so an ARM laptop doesn't get an x64-only installer.[4][6] And "Windows Sandbox won't start" is usually a virtualization switch, not a broken PC.

1. 32-bit vs. 64-bit: how much memory it can point at

The "bits" are the size of a memory address. A 32-bit CPU can name 232 addresses: 4 GB, and that's the ceiling for RAM and device memory together. A 64-bit CPU can name 264: about 16 exabytes, far beyond any PC (the OS sets its own, lower limit).[1]

NameMeansRemember
x8632-bit Intel-compatible (named after the 8086 family)4 GB ceiling; a 32-bit OS can't run 64-bit apps
x64 (also AMD64, x86-64)64-bit Intel/AMDRuns 64-bit and 32-bit apps; 32-bit ones install to Program Files (x86)
ARM (ARM64)A different instruction set, licensed by Arm Ltd.Low power, less heat: phones, tablets, many thin laptops

ARM isn't a faster or slower x86; it's a different language of instructions. Software built for x64 doesn't run natively on ARM. Windows 11 on ARM can emulate most x64 apps, but drivers must be built for ARM64.[4]

2. Cores and threads

  • Single-core: one processing unit, one thing at a time. Old CPUs.[3]
  • Multicore: several complete cores on one chip (2, 8, 24…). Real parallel work.
  • Multithreading (Intel calls it Hyper-Threading; generically SMT): one core runs two threads, so Windows sees two logical processors per core. The gain is modest (roughly 15–30%), not double, and the OS must support it.[3]

3. Virtualization support

Modern CPUs have extra instructions that let a hypervisor run virtual machines efficiently: Intel VT-x and AMD-V. They're often off in the BIOS/UEFI by default (lesson 0059). Hyper-V, Windows Sandbox and WSL 2 need them, and Hyper-V also needs a 64-bit CPU with SLAT (second-level address translation).[5]

Rule of thumb

x86 = 32-bit = 4 GB. x64 = 64-bit = Windows 11. ARM = battery life, needs ARM64 drivers. Logical processors = cores × 2 when multithreading is on. VM won't start? Turn on VT-x / AMD-V in the firmware.

Try it (2 minutes)

Open Task Manager → Performance → CPU. Under the graph, find Cores, Logical processors and Virtualization (Enabled/Disabled). For the architecture too, run this in PowerShell:[7]

Get-CimInstance Win32_Processor | Format-List Name, AddressWidth, NumberOfCores, NumberOfLogicalProcessors, VirtualizationFirmwareEnabled
$env:PROCESSOR_ARCHITECTURE

AddressWidth is 64 on a 64-bit OS. PROCESSOR_ARCHITECTURE says AMD64 (x64, Intel or AMD alike) or ARM64. If Hyper-V is already running, VirtualizationFirmwareEnabled can show False even though it's on; Task Manager is the better check then.

Before checking: if Logical processors is exactly twice Cores, what does that tell you? (then click to check)

Multithreading (Hyper-Threading/SMT) is on: each core runs two threads. If the two numbers are equal, the CPU doesn't support it or it's turned off. (Some newer Intel chips mix core types, so the ratio isn't always exactly 2.)

Practice

Answer from memory before scrolling back up.

An older desktop has 8 GB of RAM installed, but Windows reports only about 3.5 GB usable. The memory tests fine. What's the most likely cause?

A 32-bit OS can address only 4 GB in total, and part of that space goes to devices, so you see around 3.x GB.[1] Installing 64-bit Windows (on a 64-bit CPU) unlocks all 8 GB.

Task Manager on a user's PC shows Cores: 8 and Logical processors: 16. It has one CPU socket. What explains the 16?

Multithreading (Hyper-Threading/SMT) lets each physical core run two threads, so Windows sees 16 logical processors.[3] It's 8 real cores, and the speedup is well short of double.

On a 64-bit Windows 11 Pro laptop with a modern Intel CPU, Windows Sandbox won't start and says virtualization isn't available. What should you do first?

The CPU supports it, but VT-x (AMD: AMD-V) is often off in the BIOS/UEFI. Turn it on and Task Manager's CPU page shows Virtualization: Enabled.[5] It's already 64-bit, and RAM or threads aren't the issue.

A team wants thin, fanless laptops with all-day battery life. Their apps are web-based. Which processor type fits best?

ARM designs use less power and make less heat, which is why they dominate phones and tablets and suit thin laptops.[1][4] Check drivers and any desktop apps for ARM64 support first.

From memory: name the four CPU features from objective 3.5 and one fact about each. (then click to check)

32/64-bit: x86 tops out at 4 GB; x64 runs Windows 11. ARM: low power, needs ARM64 software or emulation. Cores/multithreading: more cores = real parallel work; multithreading = two threads per core. Virtualization support: VT-x / AMD-V, switched on in the firmware.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

A server farm needs its TLS keys in one hardened place, with encryption offloaded from the servers. TPM or HSM, and why? (lesson 0060, 1 day ago)

HSM: centralized key storage and crypto offload for many systems. A TPM protects only the one device it's in.

A PC must boot Windows from a 4 TB drive. Which firmware type and which partition style do you need? (lesson 0058, 3 days ago)

UEFI with a GPT disk. Legacy BIOS with MBR can't boot past about 2 TB.

A new build powers up its fans but never shows anything on screen. Which motherboard power plug do you check first, and where is it? (lesson 0054, 7 days ago)

The 4- or 8-pin CPU power plug (EPS12V), near the CPU socket, usually top-left. The 24-pin main plug alone isn't enough.
