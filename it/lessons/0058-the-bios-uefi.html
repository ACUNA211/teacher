The first code that runs: the BIOS and UEFI

About 10 minutes. Last week you built up the motherboard: size, plugs, slots, socket. Today: the firmware on that board, the program that runs before Windows does.[1] The win: say what the BIOS does at power-on, tell legacy BIOS from UEFI, and read any PC's firmware version and mode in under a minute.

Why this matters at work

Device compliance often depends on the firmware. A Windows 11 PC must start in UEFI mode with Secure Boot available,[4] and an Intune compliance policy can require Secure Boot to be on.[5] When a laptop is marked "not compliant" and the user loses access to company apps, the fix can be in the firmware, not in the account.

1. What the BIOS does

BIOS (Basic Input/Output System) is firmware: software stored on a flash chip on the motherboard. It's the first thing that runs when you press power.[1] Its job, in order:

  1. POST (power-on self-test): check the CPU, memory, video and other basics. Errors show as a message, beep codes or lights.[2]
  2. Find a boot device using the boot order (SSD, USB, network…).
  3. Hand off to the operating system's boot loader. From here on, Windows is in charge.

Some boards carry two BIOS chips: a main and a backup. If the main one is damaged (say, by a failed update), the board can recover from the backup.[1] The settings you choose (boot order, passwords) are saved in non-volatile memory; a small coin-cell CMOS battery keeps the real-time clock running when the PC is unplugged.

2. Legacy BIOS vs. UEFI

Almost every PC sold today uses UEFI (Unified Extensible Firmware Interface), the modern replacement. People still say "BIOS" for both, and so does the exam.[2]

Legacy BIOSUEFI
Setup screenText only, keyboardGraphical, mouse works
Boot driveMBR disks; can't boot past ~2 TBGPT disks; boots from drives over 2 TB[3]
Devices before the OSVery limitedCan use USB, network and modern storage
SecurityNone built inSecure Boot: only signed boot software runs
Windows 11Not supportedRequired[4]

Many UEFI boards can still pretend to be an old BIOS (a "legacy" or CSM mode). Windows then reports BIOS Mode: Legacy, and Secure Boot can't be on.

3. Updating the firmware ("flashing")

Board and laptop makers release firmware updates to fix bugs, close security holes and support newer CPUs (remember the same-socket CPU that needed a BIOS update). Get the update only from the maker, keep the PC on power during the update, and never switch it off halfway: an interrupted flash can leave a board that won't start (unless it has a backup chip).[1] To open the setup screen, press the maker's key at power-on (often Del, F2 or F10), or in Windows go to Settings → System → Recovery → Advanced startup → Troubleshoot → Advanced options → UEFI Firmware Settings.

Rule of thumb

Power on → POST → boot device → OS. The BIOS lives on a flash chip; the backup chip is the safety net. UEFI = graphical, GPT, drives over 2 TB, Secure Boot, Windows 11. Legacy BIOS = text, MBR, none of those. Flash firmware only from the maker, and never cut the power mid-update.

Try it (2 minutes)

  1. Press Win+R, type msinfo32. In System Summary, find BIOS Version/Date, BIOS Mode (UEFI or Legacy) and Secure Boot State (On, Off or Unsupported).[6]
  2. Or in PowerShell:[7] 
    Get-CimInstance Win32_BIOS | Select-Object Manufacturer, SMBIOSBIOSVersion, ReleaseDate
Confirm-SecureBootUEFI    # run as administrator: True = Secure Boot on

SMBIOSBIOSVersion is the version string you compare with the maker's download page. Confirm-SecureBootUEFI returns True or False, or an error saying the cmdlet isn't supported on a legacy-BIOS PC.[6]

Before checking: msinfo32 shows BIOS Mode: Legacy. What will Secure Boot State say, and could this PC pass the Windows 11 check? (then click to check)

Secure Boot needs UEFI, so it will be Unsupported (or Off). The PC fails the Windows 11 check as it is set up now. If the board is UEFI-capable, switching the boot disk to GPT and turning off legacy/CSM mode fixes it, but that's a planned job, not a quick toggle.

Practice

Answer from memory before scrolling back up.

A PC powers on, the fans spin, but it beeps several times and never shows the logo or starts Windows. Which firmware stage found the problem?

POST runs before anything else and reports hardware faults with messages, beep codes or lights.[2] The boot loader and Windows never got a turn.

A technician installs a new 4 TB drive as the only drive in a PC and wants Windows to boot from all of it. What must the firmware and disk use?

To use more than 2 TB, the disk must be GPT, and Windows boots from GPT only on UEFI firmware.[3] A legacy BIOS can use a big GPT disk as a data drive, not as the boot drive.

Halfway through a firmware update, a desktop loses power. Now it won't POST. The board has a second firmware chip. What's the best next step?

An interrupted flash can corrupt the main BIOS. Boards with a main and backup chip can restore from the backup (follow the maker's steps).[1] Windows and the boot order don't matter until POST works again.

An Intune compliance report flags a laptop: "Secure Boot not enabled". msinfo32 shows BIOS Mode: Legacy. What's the root cause?

Secure Boot is a UEFI feature. In legacy (CSM) mode it can't be on, so the compliance check fails.[5] The fix is in the firmware setup (and the disk must be GPT), not in the user's account.

From memory: the three jobs the BIOS does between pressing power and Windows starting. (then click to check)

1. POST (test the hardware). 2. Find a boot device using the boot order. 3. Hand off to the operating system's boot loader.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

A user's new graphics card runs slower than expected and the slot is labeled "x16 (x4 mode)". What does that mean, and does the card still work? (lesson 0055, 3 days ago)

The slot is physically x16 but wired with only 4 lanes. The card works, with less bandwidth. Move it to a full x16 slot (usually the top one).

An M.2 SSD fits the slot but the PC doesn't see it. Name the three things to check. (lesson 0051, 7 days ago)

The key (B, M or B+M), the length (for example 2280), and whether the slot speaks SATA or NVMe. A matching key doesn't guarantee the slot supports the drive's interface.

An employee leaves and their personal (BYOD) phone had company email. Retire or wipe, and why? (lesson 0028, 30 days ago)

Retire: it removes only the company's data and apps. A wipe erases everything, including the person's own photos and data, which is wrong for a device the company doesn't own.
