802.11 Wi-Fi standards

About 10 minutes. Yesterday: the bands and channels. Today: the standards that use them. Every Wi-Fi device speaks one or more versions of IEEE 802.11, and the box says either the letters (802.11ax) or the friendly name (Wi-Fi 6). You need to translate both ways.

Why this matters at work

"The new access point is Wi-Fi 7 but this laptop is still slow" usually means the laptop's adapter is older: a connection runs at the best standard both ends share. One command (below) tells you what an adapter supports, so you can tell a hardware limit from a network problem before anyone replaces anything.

The standards in one table

802.11 is the IEEE family of wireless LAN standards; each amendment gets letters. In 2018 the Wi-Fi Alliance added simple generation numbers for the newer ones.[2] Speeds are theoretical maximums: real throughput is much lower.

Sources: a/b/g/n speeds and bands [1][3]; generation names, bands and n/ax/be speeds [2]. 802.11ac's top figure depends on how many antennas (streams) and how wide a channel are used, which is why sources quote 3.5 or 6.9 Gbps.[4]

Three ideas that make the table stick

  • The names count up from n. n = 4, ac = 5, ax = 6, be = 7. The old a, b and g never got official numbers.
  • Bands follow history. b and g live in 2.4 GHz, a in 5 GHz. n was the first to use both. ac went 5 GHz only. ax went back to both, and 6E/7 added the new 6 GHz band from lesson 0006.
  • Newer talks to older, at the older speed. Standards are backward compatible within a band: a Wi-Fi 6 access point still serves an 802.11n laptop, just at n speeds.[1] But a 2.4 GHz-only 802.11g device can never join a 5 GHz-only network.

Where did the speed come from? Mostly from wider channels (yesterday's bonding) and MIMO: several antennas sending separate streams at once. 802.11n introduced MIMO; 802.11ac added multi-user MIMO, sending to several clients at the same time.[4]

Memory hooks

b = 2.4 and 11, a = 5 and 54, g = 2.4 and 54. n4, ac5, ax6, be7. ac is the 5-only one. The link runs at the best standard both ends share.

Try it (2 minutes)

On a Windows laptop, open a terminal and run:[5]

netsh wlan show drivers

Find the Radio types supported line. That's every 802.11 standard the adapter can speak:

Radio types supported     : 802.11b 802.11g 802.11n 802.11a 802.11ac 802.11ax

Your list will differ. The newest letters on it are the adapter's ceiling: ax means Wi-Fi 6 (6E if it also shows the 6 GHz band in netsh wlan show interfaces). Compare with the Radio type line from yesterday's show interfaces: that's the standard the current connection actually uses.

Practice

Answer from memory before scrolling back up.

A spec sheet says a laptop supports "Wi-Fi 6". Which 802.11 standard is that?

The generation names count up from n: n is Wi-Fi 4, ac is Wi-Fi 5, ax is Wi-Fi 6 (and 6E when it adds 6 GHz), be is Wi-Fi 7.

A warehouse barcode scanner only supports 802.11g. The new access points broadcast on 5 GHz only. What happens?

802.11g is a 2.4 GHz standard. Backward compatibility only works within a band, so a 2.4 GHz-only radio never hears a 5 GHz-only network. Turning on 2.4 GHz at the access point would let it join at g speeds.

A Wi-Fi 7 access point is installed, but a user's laptop reports Radio type: 802.11ac. Why?

A connection uses the best standard both ends share. The access point speaks be, but this laptop tops out at ac (Wi-Fi 5), so they meet at ac. And ac is 5 GHz only, so it isn't a 2.4 GHz fallback. netsh wlan show drivers confirms the adapter's ceiling.

Which standard was the first to work in both the 2.4 GHz and 5 GHz bands?

802.11n (Wi-Fi 4) ran in both bands and introduced MIMO. g was 2.4 GHz only, a was 5 GHz only, and ac is 5 GHz only.

From memory: match n, ac, ax and be to their Wi-Fi numbers, and name the one that is 5 GHz only. (then click to check)

n = Wi-Fi 4, ac = Wi-Fi 5, ax = Wi-Fi 6 (6E with 6 GHz), be = Wi-Fi 7. 802.11ac is 5 GHz only.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

Lower vs higher Wi-Fi frequency: which reaches farther, which is faster? And why do wide 160 MHz channels cause more interference between neighbors? (lesson 0006, yesterday)

Lower (2.4 GHz) reaches farther and through walls; higher (5, 6 GHz) is faster but shorter-range. Bonding into wide channels leaves fewer separate channels, so nearby access points end up sharing them.

A laptop joins Wi-Fi but gets no address. Which protocol failed, on which ports, and why must it use UDP? (lesson 0004, 3 days ago)

DHCP: server on UDP 67, client on UDP 68. The client has no address yet, so it can't set up a TCP connection; it broadcasts and waits.

A live video call drops a few packets and keeps going instead of pausing to re-send them. TCP or UDP, and why? (lesson 0002, 5 days ago)

UDP. It's connectionless and doesn't re-send lost data, so real-time traffic stays on time. TCP would stall to recover every lost packet.
