Lanes, not length: PCI and PCIe expansion slots

About 10 minutes. Yesterday was the cables and headers on the board. Today is the long slots where expansion cards go: graphics, network, sound, capture. Messer's 3.5 video covers two families: old PCI and modern PCI Express (PCIe).[1] The win: read "x16 (x4 mode)" on a spec sheet and know what it means.

Why this matters at work

A desktop that's "slow on the network" after someone added a 10-gigabit card, or a second monitor that's blank after a graphics card was installed: both often come down to which slot the card went in, or which port the cable went in. Thirty seconds with the board manual beats an hour of driver reinstalls.

1. PCI: the old parallel bus

PCI (Peripheral Component Interconnect) is parallel: many bits travel side by side over a shared bus, 32-bit or 64-bit wide.[1] You'll still meet it on old PCs and in exam questions. On new boards it's gone: PCIe replaced PCI (and older slots like AGP for graphics).[1]

2. PCIe: serial lanes

PCI Express is serial: data moves over lanes, each a point-to-point link (one pair of wires each way). More lanes = more bandwidth. A slot is named for how many lanes it can hold: x1, x4, x8, x16 (say "by sixteen").[1][2]

SlotSizeTypical cards
x1ShortestNetwork, sound, Wi-Fi, USB add-on cards
x4 / x8MediumNVMe adapter cards, fast (10 Gb+) network cards, RAID controllers
x16Longest, often reinforcedGraphics cards (the top slot, nearest the CPU)[3]

Each generation roughly doubles the speed per lane: PCIe 3.0 ≈ 1 GB/s, 4.0 ≈ 2 GB/s, 5.0 ≈ 4 GB/s per lane, each direction. Multiply by the lanes: a PCIe 4.0 x16 slot ≈ 32 GB/s.[2] Generations are backward compatible: a 3.0 card works in a 5.0 slot, at 3.0 speed.

Recall from lesson 0051: an NVMe M.2 drive is a PCIe device too, usually on 4 lanes (x4).

3. Which card fits which slot

  • Small card → bigger slot: works. An x1 card runs fine in an x16 slot (it just uses one lane).[2]
  • Big card → smaller slot: doesn't fit (unless the slot is open-ended at the back).
  • Size ≠ speed. A full-length x16 slot may be wired with only 4 lanes. The manual writes it as "x16 (x4 mode)" or "x16 @ x4": physically x16, electrically x4.[4] On many boards, filling a second slot or an M.2 socket also drops another slot's lanes, because they share them.
Rule of thumb

PCI = parallel and old; PCIe = serial lanes. The number after the x is lanes. Card fits in its size or bigger. The physical size tells you what fits; the manual's lane table tells you how fast it runs. Graphics card → top x16 slot.

Try it (2 minutes)

On a Windows desktop with a graphics card, open PowerShell and run:[5]

Get-PnpDevice -PresentOnly -Class Display |
  Get-PnpDeviceProperty -KeyName DEVPKEY_PciDevice_CurrentLinkWidth, DEVPKEY_PciDevice_MaxLinkWidth |
  Format-Table KeyName, Data

MaxLinkWidth is how many lanes the card supports; CurrentLinkWidth is how many it's using now (a number like 16 or 8). On a laptop with only built-in graphics, it may show nothing: that's fine. A free tool like GPU-Z shows the same thing as "Bus Interface".

Before checking: Max says 16, Current says 4. Name two likely causes. (then click to check)

The card is in an x16 slot wired as x4 (often the lower slot, run by the chipset), or the slot shares lanes with something else that's installed (a second card or an M.2 drive). Move it to the top x16 slot and check the manual's lane table. (Some cards also drop speed when idle to save power, but that usually lowers the generation, not the lane count.)

Practice

Answer from memory before scrolling back up.

A technician has a PCIe x1 network card. The only free slot on the board is a PCIe x16. What happens?

A smaller PCIe card fits and works in a bigger slot. It only uses the lanes it has, so an x1 card uses one lane.[2] The reverse (x16 card in an x1 slot) doesn't fit.

A board manual lists "PCIEX16_2: x16 (x4 mode)". A user installs a new graphics card there and it benchmarks slower than expected. Why?

"x16 (x4 mode)" means physically x16 but electrically x4: the card fits but gets a quarter of the lanes.[4] Move it to the primary x16 slot (usually the top one, wired to the CPU).

What is the main technical difference between PCI and PCI Express?

PCI is a shared parallel bus (32- or 64-bit). PCIe sends data serially over point-to-point lanes, and adds bandwidth by adding lanes.[1]

A PCIe 4.0 network card is installed in a PCIe 3.0 x4 slot. What's the result?

PCIe generations are backward compatible: the link runs at the speed of the older side, here 3.0 (about half the per-lane speed of 4.0).[2]

From memory: what does the "16" in "PCIe x16" count, and what's usually in that slot? (then click to check)

It counts lanes (serial links). The x16 slot usually holds the graphics card. x1 slots take small cards like network or sound.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

A new graphics card is installed but the PC won't start, and the card has empty 8-pin sockets on its edge. Which plug is missing, and how is it different from the CPU plug? (lesson 0054, 1 day ago)

The 6/8-pin PCIe (6+2) power plug from the PSU. It looks like the 4/8-pin CPU (EPS12V) plug but is wired differently, so don't swap them. The PCIe plug goes into the card; the CPU plug goes into the board near the socket.

A server has four drives in RAID 5. One fails. Is data lost? What if a second fails before the rebuild? (lesson 0052, 3 days ago)

One failure: no data lost; the array is degraded and rebuilds from parity onto a replacement. A second failure before the rebuild finishes: data lost. RAID 6 survives two. And RAID is still not a backup.

Which of VGA, DVI, HDMI and DisplayPort are analog, digital, or either? Which DVI type carries both? (lesson 0041, 14 days ago)

VGA: analog. HDMI and DisplayPort: digital (with audio). DVI: depends on type: DVI-A analog, DVI-D digital, DVI-I both. Bonus tie-in to today: with a graphics card in the x16 slot, plug the monitor into the card's ports, not the board's.
