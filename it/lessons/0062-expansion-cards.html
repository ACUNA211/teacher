Adding a capability: expansion cards

About 10 minutes. In lesson 0055 you learned the PCIe slots. Today: what goes in them. The exam names four cards: sound, video, capture and network, plus one habit: get the driver right.[1] The win: given a user's request, name the card that solves it and install it in the right order.

Why this matters at work

Most "my new card doesn't work" tickets are driver tickets. In a managed fleet, Intune's Windows driver update policies let an admin review, approve or pause driver updates from Windows Update, so only approved drivers install.[5] Knowing which device class a driver belongs to (display, network, audio) is how you read that list.

The idea: the board does the basics, a card does more

Almost every motherboard already has integrated (onboard) audio, graphics and a network port. You add a card when you need more: more quality, more speed, more ports, or something the board can't do at all.[1]

CardWhat it addsRemember
Sound cardBetter audio in and out: more channels, cleaner recording, pro inputsOnboard audio is fine for most users; recording studios add a card (or a USB audio interface)
Video adapter (graphics card)A discrete GPU with its own memory, for gaming, video editing, 3D, many monitorsGoes in the top x16 slot; big ones need PSU power plugs (lesson 0054)
Capture cardBrings video in from a camera, console or another PCVery high throughput, so usually PCIe; external USB versions exist
Network interface card (NIC)A faster wired port (2.5 or 10 Gb/s), a second port, or Wi‑FiWired = RJ45; wireless cards have antennas

Integrated vs. discrete graphics

Integrated graphics live inside the CPU (or chipset) and borrow system RAM. Fine for office work. A discrete graphics card has its own GPU and its own video memory. For high-end graphics, video editing or gaming, you want discrete.[1] The classic mistake: after installing the card, the monitor cable is still in the motherboard's video port, so the new card does nothing. Plug the monitor into the card.

Ports are a direction clue: a graphics card's HDMI ports are outputs. To record a console's HDMI signal you need a capture card's HDMI input.

Drivers: read first, then install

  1. Read the card's documentation. Some hardware wants its driver installed before the card goes in; other cards want the card first, then the driver.[1]
  2. Get the latest driver from the manufacturer's website, not the disc in the box (it's usually old) and never a random download site.[1]
  3. Check Device Manager. A yellow warning icon or an "Unknown device" means Windows sees the card but has no working driver.

Replacing onboard audio or networking with a card? You can disable the onboard device in the BIOS/UEFI (lesson 0059) so Windows doesn't use the wrong one.

Rule of thumb

Sound = audio quality. Video = graphics out. Capture = video in. NIC = network. Onboard covers the basics; a card adds more. Docs first, driver from the maker's site, monitor into the card.

Try it (2 minutes)

List the display, network and audio devices Windows knows about. In PowerShell:[3]

Get-PnpDevice -PresentOnly -Class Display, Net, Media | Sort-Object Class | Format-Table Class, Status, FriendlyName

Every line should show Status OK. Error or Unknown points to a driver problem. On a laptop you may see two display adapters: integrated and discrete. Same check without PowerShell: pnputil /enum-devices /class Display, or Device Manager (devmgmt.msc).[4]

Before checking: under the Net class you'll likely see more entries than you have network ports. Why? (then click to check)

The Net class holds every network adapter Windows uses, not just physical cards: Wi‑Fi, Bluetooth networking, VPN adapters and Hyper-V virtual switches all show up there. The physical NIC is usually the one named after a chip maker.

Practice

Answer from memory before scrolling back up.

A user edits 4K video on a desktop that uses the graphics built into its CPU. Playback in the editor stutters. Which upgrade helps most?

Integrated graphics share system RAM and are built for basics. For video editing, gaming and high-end graphics, a discrete graphics card with its own GPU and memory is the fix.[1] A capture card brings video in; it doesn't render anything.

A marketing team wants to record live footage from a camera's HDMI output on a desktop PC. Which card do they need?

A capture card takes video in from an external source. It needs high throughput, so it usually sits in a PCIe slot.[1] A graphics card's HDMI ports are outputs only.

A tech unboxes a new network card for a workstation. Before opening the case, what should they do first?

Some cards need the driver installed before the hardware, others after. The documentation says which; then get the latest driver from the manufacturer's site.[1]

A user says the new graphics card you installed made no difference in their design app. Their monitor cable goes to the HDMI port near the USB ports on the back. What's the fix?

The ports grouped with the USB ports belong to the motherboard (integrated graphics). The discrete card's ports are lower down, on the slot cover. Plug the monitor into the card so it does the work.

From memory: name the four expansion cards from objective 3.5, what each adds, and the three driver steps. (then click to check)

Sound: better audio. Video: discrete graphics out. Capture: video in. NIC: faster, extra or wireless network. Drivers: read the docs (before or after?), download the latest from the maker, check Device Manager.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

A PC's spec sheet says "x86". What's the memory ceiling, and can it run Windows 11? (lesson 0061, 1 day ago)

x86 is 32-bit: 232 addresses = 4 GB total (about 3.x GB usable RAM). No: Windows 11 needs a 64-bit CPU (x64 or ARM64).

Users at a kiosk keep booting from USB sticks. Which two firmware settings stop that, and which password stops them changing it back? (lesson 0059, 3 days ago)

Put the internal drive first in the boot order and turn off USB in the boot options. Then set a supervisor (admin) password so nobody can change the settings. A user password would stop the PC starting at all.

Today's graphics card is an x16 card. Which slot does it go in, and what does "x16 (x4 mode)" in a manual mean? (lesson 0055, 7 days ago)

The top x16 slot (wired with all 16 lanes). "x16 (x4 mode)" means the slot is physically x16 but only wired with 4 lanes: the card fits but runs slower.
