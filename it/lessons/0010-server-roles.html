Server roles: who hands out what

About 10 minutes. You already know the ports for most of these services (lessons 0003–0005). Today flips the view: the exam calls them server roles, the jobs a server does for everyone else on the network.[1] The useful skill is working backwards: from what the user can't do to which role is down.

Why this matters at work

Microsoft Entra ID is an authentication server run as a cloud service, and it does all three A's below. It checks who you are (authentication), Conditional Access and roles decide what you may do (authorization), and the sign-in logs record who signed in, with which app, to which resource, and whether it failed and why (accounting).[3] When you read a sign-in log to explain a lockout, you're using the "accounting" part of AAA.

Eight roles, one sentence each

Read each row as "this server hands out ___." Exam objective 2.3 lists these server roles:[1]

The first four rows are review in disguise: DNS and DHCP from lesson 0001 and 0004, file sharing from 0005, mail from 0004. Three new ideas need a closer look.

Print server

One place that holds the printer drivers and the print queue for a shared printer, so every PC sends jobs there instead of straight to the printer. Many printers can act as their own print server; bigger sites use a dedicated one.[1] Clue: if everyone's jobs are stuck, look at the server's queue, not one PC.

Syslog

A standard way for devices (switches, firewalls, servers) to send their log messages to one central syslog server, usually over UDP port 514. Every message carries a severity from 0 (emergency) to 7 (debug): the lower the number, the worse the news.[2] Often the collected logs feed a SIEM (security information and event management), which searches and correlates them in one database.[1]

AAA

Three questions, always in this order:

  • Authentication: who are you? (password, security key, MFA)
  • Authorization: what are you allowed to do? (groups, roles, policies)
  • Accounting: what did you do, and when? (logs of sign-ins and resource use)

Instead of every switch, VPN and app keeping its own user list, they all ask one AAA server.[1]

Memory hooks

Work backwards from the symptom. Names fail → DNS. 169.254 → DHCP. Everyone's printing stuck → print server. Syslog: 514, and 0 is the emergency. AAA = who, what, and the receipt.

Try it (2 minutes)

On a Windows PC, open PowerShell and run:

Get-Printer | Select-Object Name, Type, ComputerName

You'll see something like:

Name                         Type       ComputerName
----                         ----       ------------
Microsoft Print to PDF       Local
\\print01\Floor2-Color        Connection print01

Your list will differ (the names here are made up). Local = the PC handles the printer itself. Connection = a shared printer that lives on a print server, and ComputerName names that server. If a user's Connection printer fails and so does everyone else's on the same server, you've found your role. On a home PC you may only see Local printers: that's fine, it just means no print server.

Practice

Answer from memory before scrolling back up.

Several users report that their documents sit in the queue and never print. They all use the same shared printer, connected through one server. Where do you look first?

The print server holds the shared queue for every client. When several users of the same shared printer are stuck, the common point is that server's queue (or the printer behind it), not anything on one PC.

A firewall sends a log message marked severity 0, and a switch sends one marked severity 6. Which needs attention first?

Syslog severities run from 0 (emergency: the system is unusable) to 7 (debug). Lower is worse, so 0 beats 6 (informational). UDP delivery has nothing to do with how urgent the message is.

A user signs in successfully, but gets "access denied" when opening a finance app that their team isn't assigned to. Which part of AAA blocked them?

The sign-in worked, so authentication passed. Being refused a specific resource is authorization: the system knows who you are and decided you aren't allowed. Accounting would only record the attempt.

After an incident, a manager asks: "Show me every time this account signed in last week, and from where." Which AAA function answers that?

Accounting is the record of what happened: who signed in, when, from where, and to what. In Microsoft Entra ID that's the sign-in logs.

From memory: name the three A's in order, with one example of each from your own sign-in today. (then click to check)

Authentication (your password plus MFA prompt), authorization (being allowed into the apps your groups grant), accounting (the sign-in log entry that recorded it).

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

A passive RFID badge has no battery. So where does its power come from, and why does that keep its range short? (lesson 0009, 1 day ago)

The reader's radio signal powers the tag just long enough for it to reply. That borrowed energy is small, so the tag only works close to the reader. Active tags carry their own battery and reach much farther.

What's the Wi-Fi generation name for 802.11ax, and which bands can it use? (lesson 0007, 3 days ago)

Wi-Fi 6, on 2.4 and 5 GHz. The 6E version adds the 6 GHz band.

The company intranet runs on an internal web server. Which port should the browser use to reach it securely, and which port would you use to open a full remote desktop on that server? (lesson 0003, 7 days ago)

HTTPS on TCP 443 for the web page; RDP on TCP 3389 for the remote desktop.
