Match the socket: motherboard and CPU compatibility

About 10 minutes. This week you met the board's size, plugs and slots. Today is the last piece before BIOS: which CPU a board accepts, and how desktop, server and mobile boards differ.[1] The win: look at a CPU and a board and say "yes, no, or check the support list".

Why this matters at work

Someone asks for "a faster processor" in their laptop, or wants to drop a spare CPU into an old desktop. The answer starts here: most laptop CPUs can't be swapped at all, and a desktop CPU only fits a board with the same socket and firmware that knows it. Getting this right saves a parts order that can't be used.

1. The socket decides: Intel vs. AMD

A motherboard is built for one CPU family. An Intel CPU needs a board with an Intel socket; an AMD CPU needs an AMD socket. They never cross over.[1] Within a brand, each socket generation has its own name (for example AMD AM4 and AM5), and they don't cross over either.

Sockets come in two physical styles:[2]

StyleWhere the pins areExamples
LGA (land grid array)Pins in the socket; flat pads on the CPUIntel desktop CPUs; AMD AM5 (LGA 1718)
PGA (pin grid array)Pins on the CPU; holes in the socketOlder AMD desktop, e.g. AM4
BGA (ball grid array)No socket: CPU soldered to the boardMost laptops, tablets, small PCs

Either socket style uses a locking lever: line up the CPU's corner mark with the socket's, drop it in with no force, close the lever.[1] Bent pins are the classic damage: on the CPU for PGA, in the socket for LGA.

2. Same socket isn't always enough

A newer CPU may share a socket with an older board but need a BIOS/UEFI update before it will start (POST). Check the board maker's CPU support list, not just the socket name.[3] The board also fixes the memory type: a DDR4 board won't take DDR5 (lesson 0047).

3. Desktop, server, mobile

BoardWhat's different
DesktopOne socket; upgradable CPU, RAM and cards; form factor ATX / micro-ATX / ITX (lesson 0053)
ServerOften multisocket: two or more physical CPUs on one board; many memory slots (usually ECC, lesson 0048); built to fit a 19-inch rack[1]
MobileCustom-shaped to the laptop; CPU (and often RAM) soldered; little or nothing to upgrade except storage[2]
Rule of thumb

Brand → socket → support list. Intel CPU, Intel socket; AMD CPU, AMD socket; then confirm the exact model is on the board's CPU support list (maybe after a BIOS update). LGA = pins in the socket, PGA = pins on the CPU, BGA = soldered. Server = multisocket + lots of ECC RAM. Laptop CPU = not upgradable.

Try it (2 minutes)

On any Windows PC, open PowerShell and run:[4]

Get-CimInstance Win32_Processor | Format-Table Name, SocketDesignation, NumberOfCores
(Get-CimInstance Win32_ComputerSystem).NumberOfProcessors

Name is the CPU model (search it plus "support list" with your board model from lesson 0053's Win32_BaseBoard command). SocketDesignation is whatever the firmware reports: on desktops often a socket name like "LGA1700" or "AM5", on laptops often just "CPU 1" or "U3E1" (it's soldered). NumberOfProcessors counts physical CPU packages: 1 on desktops and laptops, 2+ on a multisocket server.

Before checking: a server shows NumberOfProcessors = 2 and two rows from Win32_Processor. What kind of board is it? (then click to check)

A multisocket (here dual-socket) server board: two separate physical CPUs on one motherboard. Each row is one CPU package; cores are counted inside each.

Practice

Answer from memory before scrolling back up.

A technician has a spare AMD desktop CPU and an old desktop with an Intel board. Can the CPU be installed?

Intel and AMD CPUs use different sockets: an AMD CPU needs a board with an AMD socket.[1] No BIOS update or adapter changes that.

A new CPU has the same socket as a user's board, but after installing it the PC won't POST. The old CPU still works. Most likely fix?

A same-socket CPU can need newer firmware before the board recognizes it. Put the old CPU back, update the BIOS/UEFI, then swap in the new one, and check the board's CPU support list first.[3]

A user asks IT to upgrade the processor in their two-year-old thin laptop. What's the usual answer?

Most laptop CPUs are BGA: soldered to the board, with no socket.[2] The realistic options are more RAM or a faster SSD (if not soldered either), or a new device.

Which motherboard feature is most typical of a server board rather than a desktop board?

Server boards are often multisocket: separate physical CPUs on one board, plus lots of (ECC) memory slots.[1] Soldered CPUs are typical of laptops; ITX is a small desktop form factor.

From memory: in LGA, PGA and BGA, where are the pins (or what replaces them)? (then click to check)

LGA: pins in the socket, flat pads on the CPU. PGA: pins on the CPU. BGA: no socket; the CPU is soldered to the board with tiny solder balls.

Review: earlier lessons

Spaced retrieval: pull these from memory first, then check.

Can a PCIe x16 card go in an x1 slot? Can an x1 card go in an x16 slot? What does "x16 (x4 mode)" mean? (lesson 0055, 1 day ago)

x16 card in an x1 slot: no, it doesn't fit (unless the slot is open-ended). x1 card in an x16 slot: yes, it uses one lane. "x16 (x4 mode)": physically x16, electrically 4 lanes.

A user's old laptop takes two minutes to boot and the drive light is always on. What single upgrade helps most, and what three interfaces can an internal drive use? (lesson 0049, 7 days ago)

Replace the HDD with an SSD: no moving parts, far faster random access. Interfaces: SATA (AHCI, desktop/laptop), SAS (enterprise servers), NVMe over PCIe (fastest, usually M.2).

What's the difference between a docking station and a port replicator? (lesson 0026, 30 days ago)

A port replicator copies the laptop's existing ports. A docking station replicates ports, adds more (extra video, network) and usually charges the laptop over the same connection.
