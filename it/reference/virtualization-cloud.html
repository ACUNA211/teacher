Virtualization & cloud cheat sheet

A+ Core 1 domain 4 (11% of the exam). From lessons 0030, 0031 and 0032.

Words (objective 4.1)

Virtual machine (VM)A whole computer in software: its own OS, with CPU, memory, disk and network shared out by the hypervisor
HostThe physical computer and its operating system
GuestAn operating system running inside a VM
HypervisorVirtual machine manager: creates VMs, allocates hardware, keeps guests separated
SnapshotSaved state of a VM you can revert to; Hyper-V calls it a checkpoint

Four uses of a VM

UsePick it when
SandboxingYou need to try something isolated from the host and production; throwaway
Developing / testing softwareYou need clean, repeatable test machines
Legacy softwareAn app only runs on an older OS (limit the VM's network access: no security updates)
Cross-platformYou need a different OS than the host (Linux on Windows, several versions side by side)

Hypervisors and delivery (objective 4.1)

Type 1 (bare metal, native)Runs directly on hardware; least overhead; servers. ESXi, Hyper-V, Proxmox. Hyper-V on Windows 11 is still type 1: Windows runs in the root partition
Type 2 (hosted)Runs on top of a host OS; desktops. VirtualBox, VMware Workstation
CPU supportIntel VT-x / AMD-V, enabled in UEFI/BIOS; Hyper-V also needs SLAT
VDIDesktops run as VMs in a data center or cloud; the device only shows the screen. Data stays central; needs a good network
ContainerApp plus dependencies, shares the host OS kernel; small, starts in seconds, lighter isolation than a VM (e.g. Docker)

Cloud deployment models (objective 4.2)

PublicProvider's cloud, shared by many paying customers; nothing to buy, less control
PrivateOne organization's own cloud, usually its own data center; full control, you buy everything
HybridPrivate and public working together (e.g. on-premises AD synced to Entra ID = hybrid identity)
CommunitySeveral organizations with shared needs split the cost of one cloud

Cloud service models (objective 4.2)

ModelYou manageExample
IaaSOS, patches, apps, data (provider: hardware, network, hypervisor)Cloud VMs
PaaSYour code and data (provider adds OS and runtime)App hosting platforms
SaaSData, users, settings (provider runs the whole app)Microsoft 365, Gmail
Always the customer'sData, endpoints, accounts, access managementIn every model

Windows checks and commands

Task Manager → Performance → CPUVirtualization: Enabled; Disabled = turn it on in UEFI/BIOS
systeminfoLast lines: Hyper-V Requirements (all Yes), or "A hypervisor has been detected"
Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVMAdmin PowerShell: turn on Windows Sandbox (Pro, Enterprise, Education; not Home). Discards everything when closed
Get-VMSwitch | Select-Object Name, SwitchTypeAdmin PowerShell with Hyper-V: list virtual switches (External, Internal, Private)
Task Manager → Performance → CPUVirtual machine: Yes = you're inside a VM
Hyper-V requirements64-bit Windows Pro or Enterprise, CPU with SLAT and VT-x/AMD-V, 4 GB RAM
