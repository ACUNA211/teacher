Network settings cheat sheet

The four settings, what breaks without each, and where to look. From lessons 0001, 0002, 0003, 0004, 0005, 0006 and 0007.

TCP vs UDP

TCPUDP
StyleConnection-orientedConnectionless
Reliable, orderedYes (re-sends lost data)No
Flow controlYesNo
Typical usesWeb, email, file transfer, remote desktopLive voice/video, DNS lookups, DHCP

Ports: 0–65535 for each of TCP and UDP. Servers listen on non-ephemeral ports (well-known ones usually 0–1023). Clients use a temporary ephemeral port per connection. Ping works but the app doesn't → suspect the port (service stopped or firewall).

DNS record types (objective 2.4)

TypeAnswersRemember
AName → IPv4 addressA = Address
AAAAName → IPv6 address"Quad A": 4× the bits of IPv4
CNAMEAlias → canonical (real) namePoints at a name, never an IP; no other records on that name
MXDomain → mail server name + priorityLowest number tried first
TXTFree text read by other servicesDomain ownership proof (MS=ms…), email rules

Every record has a TTL (seconds it may be cached). Microsoft 365 custom domain: TXT to verify, MX for mail, CNAME autodiscover → autodiscover.outlook.com.

Email authentication records (all TXT-based)

RecordLives atChecksRemember
SPFexample.com (TXT)Is the sending server's IP allowed?Only one per domain; -all hard fail, ~all soft fail. M365: include:spf.protection.outlook.com
DKIMselector._domainkey.example.comValid signature, message unchanged?Private key signs, public key in DNS. M365: two CNAMEs (selector1, selector2)

Read the result in a message header: Authentication-Results: spf=pass dkim=pass dmarc=pass.

DHCP configuration (objective 2.4)

TermMeansUse it for
ScopeDHCP setup for one subnet: range + optionsOne per subnet
PoolAddresses actually handed outRange minus exclusions
ExclusionAddresses DHCP never offersStatically set devices (router, servers)
ReservationOne MAC always gets one IPPrinters and devices that must stay put
LeaseHow long the address is keptLong = stable; short = busy guest Wi-Fi
Scope optionsGateway (router), DNS servers, domain nameSettings that ride along with the address

Getting a lease: DORA (Discover, Offer, Request, Acknowledge). Renew at 50% (T1, same server), rebind at 87.5% (T2, any server), lost at 100% → DORA again or APIPA. ipconfig /all shows Lease Obtained / Lease Expires.

Commands (Windows)

ipconfig /allShow every setting on every adapter
ipconfig /release then ipconfig /renewDrop and re-request a DHCP lease
Test-NetConnection host -Port 443PowerShell: does a TCP connection to that port open? Read TcpTestSucceeded
Get-NetTCPConnection -State EstablishedPowerShell: list open TCP connections with local and remote ports
net useList mapped drives (SMB connections)
nbtstat -nShow this PC's NetBIOS names (listed = NetBIOS over TCP/IP enabled)
netsh wlan show interfacesCurrent Wi-Fi connection: radio type (802.11 standard), band, channel, signal
netsh wlan show driversWi-Fi adapter capabilities: every 802.11 standard it supports
Get-PnpDevice -Class BluetoothPowerShell: the Bluetooth radio and paired devices, with status (OK, Error, Unknown)
Get-Printer | Select-Object Name, Type, ComputerNamePowerShell: printers; Connection = shared from the print server named in ComputerName
netsh winhttp show proxySystem (WinHTTP) proxy; "Direct access" = no proxy. Browsers: Settings → Network & internet → Proxy
Resolve-DnsName name -Type A|AAAA|CNAME|MX|TXTPowerShell: ask DNS for one record type (nslookup -type=mx name also works)
