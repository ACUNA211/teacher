TCP vs UDP

TCPUDP
StyleConnection-orientedConnectionless
Reliable, orderedYes (re-sends lost data)No
Flow controlYesNo
Typical usesWeb, email, file transfer, remote desktopLive voice/video, DNS lookups, DHCP

Ports: 0–65535 for each of TCP and UDP. Servers listen on non-ephemeral ports (well-known ones usually 0–1023). Clients use a temporary ephemeral port per connection. Ping works but the app doesn't → suspect the port (service stopped or firewall).

Wi-Fi bands and channels

BandRangeSpeedChannels (20 MHz, non-overlapping)
2.4 GHzLongest, best through wallsSlowest, most crowded3: 1, 6, 11 (US allows 1–11)
5 GHzShorterFasterAbout 25 (numbered 36 and up)
6 GHzShortestWidest channels, least crowdedAbout 59 (Wi-Fi 6E / 7 only)

Bonding makes 40, 80, 160 (Wi-Fi 7: 320) MHz channels: faster, but fewer fit. Check a Windows connection with netsh wlan show interfaces (Radio type, Band, Channel).

Commands (Windows)

ipconfig /allShow every setting on every adapter
ipconfig /release then ipconfig /renewDrop and re-request a DHCP lease
Test-NetConnection host -Port 443PowerShell: does a TCP connection to that port open? Read TcpTestSucceeded
Get-NetTCPConnection -State EstablishedPowerShell: list open TCP connections with local and remote ports
net useList mapped drives (SMB connections)
nbtstat -nShow this PC's NetBIOS names (listed = NetBIOS over TCP/IP enabled)
netsh wlan show interfacesCurrent Wi-Fi connection: radio type (802.11 standard), band, channel, signal
Resolve-DnsName name (-Type MX for mail servers)PowerShell: ask DNS for a name's records
