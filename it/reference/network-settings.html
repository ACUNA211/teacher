Network settings cheat sheet

The four settings, what breaks without each, and where to look. From lessons 0001 and 0002.

The four settings

SettingJobIf it's wrong
IP addressIdentifies this deviceNothing works; or APIPA 169.254.x.x
Subnet maskDefines which addresses are localLocal devices unreachable or misrouted
Default gatewayExit for all non-local trafficLocal works, internet doesn't (even by IP)
DNS serverTurns names into IP addressesIP addresses work, names fail

TCP vs UDP

TCPUDP
StyleConnection-orientedConnectionless
Reliable, orderedYes (re-sends lost data)No
Flow controlYesNo
Typical usesWeb, email, file transfer, remote desktopLive voice/video, DNS lookups, DHCP

Ports: 0–65535 for each of TCP and UDP. Servers listen on non-ephemeral ports (well-known ones usually 0–1023). Clients use a temporary ephemeral port per connection. Ping works but the app doesn't → suspect the port (service stopped or firewall).

Commands (Windows)

ipconfig /release then ipconfig /renewDrop and re-request a DHCP lease
