Hardware cheat sheet

Laptop, mobile and display hardware facts worth looking up later. From lessons 0023 and 0024 onward (displays: 0034).

Laptop parts you'll replace (objective 1.1)

PartKey factsWatch for
BatteryLithium-ion or lithium-ion polymer; modular (removable) or built inHealth = full charge capacity ÷ design capacity; low = replace
KeyboardOne key cap clips back on; many dead keys or a spill = whole keyboard (ribbon cable)Fragile clips; follow the service manual
Drive2.5-inch (SATA, same bay as a laptop HDD), M.2 (board in a slot), 1.8-inch (old)Match form factor and interface before ordering
NFC reader13.56 MHz, about 4 cm; tap a badge, phone or security key to sign in, pair or pay"Doesn't read" = not held flat on the mark
WebcamIn the screen bezel; privacy shutter, function key, activity LEDBlack image = shutter closed; Windows Hello face needs an IR camera
MicrophonesBeside the webcam or along the edges; mute key on many laptopsSame privacy settings as the camera, own Settings page

HDD → SSD migration

MethodKeepsHow
Clone (image)Windows, apps, settings, filesNew SSD on a USB-to-SATA adapter or enclosure, clone, swap
Fresh installNothing; clean startInstall Windows, reinstall apps, restore files from backup

Back up first. On a BitLocker laptop, suspend BitLocker before planned hardware or firmware work; recovery keys are often backed up to Microsoft Entra ID or AD.

Camera or mic not working: check in order

#LayerCheck
1PhysicalShutter open, camera/mic function key on
2Windows privacySettings → Privacy & security → Camera / Microphone; app allowed; Let desktop apps access… on
3DeviceDevice Manager or Get-PnpDevice: present, status OK
4PolicyGreyed out "managed by your organization" = MDM policy (Intune Allow Camera / CSP Camera/AllowCamera)

Connecting mobile devices (objective 1.2)

ItemKey facts
Micro-USB / mini-USBOlder Android and accessories; not reversible
LightningApple proprietary, 8 pins, reversible; older iPhones/iPads (iPhone 15+ use USB-C)
USB-C24 pins, reversible; data, power and video
Bluetooth pairingOn → discoverable → select → confirm code/PIN → test; PAN, ~10 m
NFCTap within a few cm: payments, sharing, quick Bluetooth pairing
TetheringPhone's cellular shared with one device over USB (or Bluetooth); appears as a new network adapter (Android: Remote NDIS based Internet Sharing Device)
HotspotPhone becomes a Wi-Fi access point for several devices; phone is the default gateway (iPhone typically 172.20.10.1)
PolicyIntune Android Enterprise: Tethering and access to hotspots = Block stops both

Mobile device accessories (objective 1.2)

ItemKey facts
Passive stylusNo battery or electronics; acts like a fingertip; no pressure sensitivity
Active stylusElectronics/battery; digitizer gives pressure sensitivity and palm rejection; needs device support
Trackpad / drawing padExternal pointing device; pen tablet for signatures, drawing, notes
Bluetooth headsetMic in use → Hands-Free Profile → mono, lower quality; workaround: laptop or USB mic for calls
Port replicatorCopies the laptop's ports; traditionally no charging; often generic USB; smaller
Docking stationCopies and adds ports, charges the laptop; often proprietary connector. Its network port is its own adapter with its own MAC

Mobile device networks (objective 1.3)

ItemKey facts
CellularLand split into cells, each with an antenna; carries voice and data. Airplane mode turns all radios off
3G / 4G LTE / 5G3G made mobile data and phone GPS practical; 4G = LTE, one converged standard; 5G = gigabit peaks, low latency, many IoT devices
5G sub-6 vs. mmWaveSub-6 GHz: wide coverage, hundreds of Mbps. mmWave: multi-gigabit, short range, blocked by walls
SIM / eSIMHolds the subscription. eSIM = built-in chip that downloads carrier profiles
IMEI · ICCID · IMSI · EIDThe phone · the SIM (or eSIM profile) · the subscriber · the eSIM chip
GPSReceive-only; at least 4 satellites for 3D position (4th corrects the clock). Indoors, phones fill in with Wi-Fi and cell towers
Sign-in locationComes from the public IP, not GPS; cellular IPs often geolocate to another city. MDM "locate device" uses the device's location services

Mobile device management (objective 1.3)

ItemKey facts
MDMOne console for all phones: allow/block apps, push business apps, disable features (camera, GPS), require lock and encryption, remove company data
BYODEmployee owns it; IT controls only a partitioned work area or work apps; personal data stays private
COPECompany owns and fully manages it; personal use allowed
Fully managed · dedicatedCompany-owned, work only · locked to a few apps, no single user (kiosk, shared)
MDM vs. MAMMDM enrolls the device. MAM (app protection) protects data inside work apps without enrollment: app PIN, block save-as/copy-paste, selective wipe; can't push apps, certificates, Wi-Fi or VPN
Retire vs. wipeRetire removes company apps, data and settings; personal data stays (BYOD offboarding). Wipe = factory reset (company devices)
Is it managed?Windows: Settings → Accounts → Access work or school. iPhone: Settings → General → VPN & Device Management. Android: a separate Work tab

Display types (objective 3.1)

TypeWhere the light comes fromRemember
LCD: TNBacklightFastest, cheapest; colors shift off-center
LCD: IPSBacklightBest color and viewing angles; costs more
LCD: VABacklightBest contrast of the three; slower than TN
CCFL backlightFluorescent tubeNeeds an inverter (DC → high-voltage AC); dim screen = lamp or inverter
LED backlightLEDs behind the LCDNo inverter; an "LED display" is an LED-backlit LCD
Mini-LEDThousands of LEDs in local dimming zonesDeep contrast, very bright, no burn-in; slight blooming
OLEDEach pixelNo backlight, perfect black; can burn in with static images
Digitizer(touch layer)Senses touch or pen, converts it to coordinates; picture fine + taps dead = digitizer

Black screen, PC running: shine a flashlight on it. Faint picture = backlight/inverter. Nothing = graphics, cable or panel; try an external monitor.

Display attributes (objective 3.1)

AttributeUnit / valuesRemember
ResolutionWidth × height (1920×1080, 2560×1440, 3840×2160)Use the native one, marked (Recommended); other values blur. Make things bigger with Scale, not resolution
Pixel densityPPI (pixels per inch)Depends on resolution and size: same 1080p is ~92 PPI at 24", ~157 PPI at 14"
Refresh rateHz (redraws per second)60 Hz standard, up to ~240 Hz gaming; new monitors often start at 60 (Settings → Display → Advanced display)
Color gamut% of a color spacesRGB web/everyday (smallest), Adobe RGB photo/print, DCI-P3 video/HDR

Commands (Windows)

Get-CimInstance Win32_VideoController | Select-Object Name, CurrentHorizontalResolution, CurrentVerticalResolution, CurrentRefreshRatePowerShell: current resolution and refresh rate per graphics adapter
powercfg /batteryreportHTML battery report: design vs. full charge capacity, cycle count, usage history. Add /output path to choose where it's saved
Suspend-BitLocker -MountPoint "C:" -RebootCount 1PowerShell (admin): suspend BitLocker for one reboot before planned hardware work; manage-bde -protectors -disable C: also works
Get-NetAdapter | Where-Object Status -eq UpPowerShell: adapters that are connected; a USB tether shows up as an extra adapter
Get-NetAdapter | Format-Table Name, InterfaceDescription, Status, MacAddressPowerShell: see which adapter (and MAC) a docked laptop really uses; a dock usually adds a USB Ethernet adapter
Get-PnpDevice -PresentOnly -Class Camera,ImagePowerShell: list cameras Windows sees and their status (OK, Error); an "IR Camera" entry means Windows Hello face is possible
