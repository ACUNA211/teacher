# IT and certs Resources

## Knowledge

- [CompTIA A+ Core 1 (V15) exam page](https://www.comptia.org/en-us/certifications/a/core-1-v15/)
  Official exam details and objectives download. Use for: deciding what's in scope. The objectives PDF is the source of truth.
- [Professor Messer: Free CompTIA A+ 220-1201 course](https://www.professormesser.com/free-a-plus-training/220-1201/220-1201-video/220-1201-training-course/)
  63 free videos (about 10 hours) mapped to every Core 1 objective. Use for: the primary source linked from each daily lesson.
- [Professor Messer: Free CompTIA A+ 220-1202 course](https://www.professormesser.com/free-a-plus-training/220-1202/220-1202-video/220-1202-training-course/)
  Core 2 counterpart. Use for: after Core 1.
- [Microsoft Learn: ipconfig](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ipconfig)
  Official command reference. Use for: Windows networking commands shown in lessons.
- [Microsoft Learn: Microsoft Entra ID documentation](https://learn.microsoft.com/en-us/entra/identity/)
  Use for: tying identity and access topics to real work.
- [Microsoft Learn: Microsoft Intune documentation](https://learn.microsoft.com/en-us/intune/)
  Use for: MDM topics (A+ 1.3) and device compliance tie-ins.

## Wisdom (Communities)

- [Professor Messer monthly study groups](https://www.professormesser.com/category/free-a-plus-training/220-1201/220-1201-study-group/)
  Live monthly Q&A about the current exam. Use for: exam-style questions and tips.
- [r/CompTIA](https://www.reddit.com/r/CompTIA/)
  Large community of test-takers. Use for: exam-day experiences and study plans. Treat "brain dump" posts as off-limits.
- [r/sysadmin](https://www.reddit.com/r/sysadmin/)
  Working admins. Use for: how things are done in real environments (wisdom beyond the exam).
